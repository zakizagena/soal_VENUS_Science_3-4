AAFiyah SCIENCE CHAMPION — PAKET WEB SOAL NOMOR 06

CARA MEMBUKA:
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Jangan memindahkan file HTML terpisah dari folder assets.
3. Buka index.html dengan Chrome, Edge, Firefox, atau browser modern lainnya.
4. Dari menu utama, pilih Soal 06. Tautan menuju pembahasan soal, materi, dan quiz sudah aktif.

HALAMAN:
- index.html          : Menu utama dan daftar 40 nomor soal (Soal 06 aktif)
- soal-06.html        : Halaman pilihan tiga jalur belajar
- bahas-soal-06.html  : Halaman grafis pembahasan dengan gambar terlampir
- materi-06.html      : Halaman grafis materi dengan gambar terlampir
- quiz-06.html        : Kuis interaktif 10 soal, skor, dan pembahasan
- assets/             : Logo dan dua infografis
